# Finanzplaner

Ein minimalistischer Monats-Finanzplaner als einzelne HTML-Datei – ohne Installation, ohne Server, ohne Abhängigkeiten.

## Benutzen

`index.html` im Browser öffnen. Fertig.

## Funktionen

- **Händische Eingabe** aller Beträge in den Kategorien Einkommen, Fixe Ausgaben, Haushalt, Abos, Essen, Hygiene, Freizeit und Sparen – jeweils mit beliebig vielen Positionen
- **Geldfluss-Diagramm**: zeigt, wohin das Einkommen fließt und was übrig bleibt
- **Kennzahlen**: Einkommen, Ausgaben, Übrig (bzw. Fehlbetrag)
- **Sparpotenzial**: wie viel pro Monat und Jahr zurückgelegt werden könnte, plus Vergleich mit der 50/30/20-Faustregel
- Helles und dunkles Design (folgt der Systemeinstellung), funktioniert auch auf dem Handy

## Daten

Alle Eingaben werden ausschließlich lokal im Browser gespeichert (`localStorage`). Es wird nichts übertragen. Beim ersten Start sind Beispielwerte eingetragen – über „Alles leeren" startest du mit einem leeren Plan.
